# QueueLite 🗓️
Appointment and Queue Management System for small clinics, salons, and consultation centers.

📚 Software Engineering Fundamentals – Course Project, Umm Al-Qura University

## 📌 What's Inside
This project covers the full software design process:
- Planning: problem statement, scope, and timeline
- Analysis: functional & non-functional requirements, user personas, use case diagram, risk assessment
- Design: UML class diagram, three-layer architecture, UI wireframes
- Testing: test scenarios, test cases, and bug reports

📄 Full report: [QueueLite Report](./QueueLite_Report.pdf)
